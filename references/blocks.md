# 积木索引

**先按「要表达什么」选积木,别一上来就画界面。**很多需求用流转图 / 矩阵表 / 时间线讲,比堆界面清楚得多。

源文件:`~/www/_blocks/index.html`(浏览器打开 `<BASE_URL>_blocks/` 直接看效果,右键查看源码抄)。
起手模板:`~/www/_template/index.html`。

| 你要表达什么 | 积木 | 类名 |
|---|---|---|
| 一个弹窗 / 表单长什么样 | 手机弹窗帧 | `.phone` |
| 这功能挂在哪个端、哪个菜单、谁看得到 | A 桌面后台外壳 | `.shell` |
| 一批数据在哪看、怎么筛、每行能干什么 | B 业务列表页 | `.dt` |
| 票据 / 小票印出来什么样 | C 小票纸卷 | `.rcpt` `.amt` |
| 一条单据实际走过的路,谁几点做了什么 | D 操作轨迹时间线 | `.tl` |
| 这次做什么不做什么、我们有什么缺什么 | E 判定矩阵表 | `.mx` `.rmk` |
| 改动落在真实界面的哪个位置(其余不动) | F 并排双栏对照 | `.cols` |
| 一张界面图讲不完的 4~6 条后果 | G 三色要点卡网格 | `.cards` |
| 这一改会动多少东西、差多少钱 | H 旧→新差异清单 | `.diffl` |
| 哪块是新的、哪个值变了 | I 内联新旧标注 | `.tag-new` `.newf` `.old` |
| 有几种结局、每种能点什么 | 状态流转图 | `.flow` |
| 一个值改前改后 | 简单对比表 | `.cmp` |
| **一条业务规则怎么变的**(模式 B) | J 规则卡 | `.rule` |
| **文件树 / 字段树 / 结构清单** | K ASCII 面板 | `pre.ascii` |
| **状态机 · 调用链**(唯一黑底) | L mermaid 黑底卡 | `.mmd` |
| **一次改动的关键数字**(N 文件 / M 表 / K 规则) | M 数字条 | `.stats` |

## 抄之前先搜类名有没有撞

后代选择器压不住顶层同名类:写了 `.mx .note` 也照样吃到 `.note` 的橙边框。已知三处已在积木库里改好名,别改回去:

- 列表页表格用 `.dt`,不是 `.tb`
- 小票小计用 `.amt`,不是 `.st`(`.st` 是分节)
- 矩阵说明列用 `.rmk`,不是 `.note`

## 颜色语义(别乱用)

| 用途 | 值 |
|---|---|
| 现状 / 已有 | 灰白常规 |
| 本次新增 / 修改 | `#16a34a` 绿 |
| 主操作按钮 | `#f59e0b` 琥珀 |
| 编号 / 强调 | `#ea580c` 橙 |
| 警告 / 失败 / 破坏性 | `#dc2626` 红 |
| 删除掉的 | 红 + 删除线 |
